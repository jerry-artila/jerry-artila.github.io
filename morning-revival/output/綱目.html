第一週 綱目

認識並經歷亞伯拉罕的神、以撒的神和雅各的神，而成爲神的以色列

讀經：創二八13，三三20，出三6、14～15，徒三13，加六16，帖前一1

第壹大點

我們的神乃是三個特別人物—亞伯拉罕、以撒、雅各—的神；這含示祂是三一神—出三15，太二八19，林後十三14：

一、

亞伯拉罕、以撒、雅各是以色列國的根基；若沒有他們，就沒有以色列國—出三15～16：

  1. 1.

    神的子民所以能成爲神的子民，是因爲他們有了亞伯拉罕、以撒、雅各的經歷；他們的經歷最終使他們成為神的子民以色列。

  2. 2.

    我們都需要有亞伯拉罕、以撒、雅各的成分；沒有這些成分，我們就不能成爲神的子民，神的以色列。

二、

在創世記這卷書中，亞伯拉罕、以撒、雅各的記載是重疊的；創世記描繪他們，不是三個分開的個人，乃是一個團體人的構成分子：

  1. 1.

    亞伯拉罕的經歷表徵對父神這獨一源頭的經歷，祂呼召人、稱義人、裝備人，使人憑信而活，且活在與祂的交通裏—十二1，十五6，十七～十八，十九29，二一1～13，二二1～18。

  2. 2.

    以撒的經歷表徵對子神的經歷，祂救贖人、祝福人，使人承受祂一切的豐富，過享受祂豐盛的生活，並活在平安中—1～14節，二五5，二六3～4、12～33。

  3. 3.

    雅各（連同約瑟）的經歷，表徵對父神的經歷，祂愛人並揀選人（瑪一2，羅九10～13）；也表徵對靈神的經歷，祂使萬有互相効力，叫愛祂的人得益處，並且變化人，使人在神聖的生命裏成熟，能祝福所有的人，治理全地，並以子神作生命供應，滿足所有的人—創二七41，二八1～三五12，三七，三九～四九，羅八28～29。

第貳大點

我們需要認識並經歷亞伯拉罕的神、以撒的神和雅各的神：

一、

亞伯拉罕信神是獨一的源頭，是那『稱無爲有』者—四17：

  1. 1.

    神的目標必須按着神的時候並藉着神的能力達成—創十七17、19、21。

  2. 2.

    神在亞伯拉罕身上作特別的工作，爲要給他看見，神作爲父的意義是甚麼—弗四6：

  3. 3.

    認識神是父，乃是認識祂是源頭，就是獨一的發起者，並且一切都是源於祂—太十五13。

  4. 4.

    我們都需要認識神是父，一切都是從祂而出—羅十一36，林前八6，弗三14～16。

二、

以撒是子最佳的表徵；在他身上我們看見，一切都是從父而來—創二四36，二五5：

  1. 1.

    按照創世記二十二章的圖畫，以撒很詳細的豫表基督。

  2. 2.

    以撒的原則乃是領受的原則—二五5，林前四7：

  3. 3.

    子神的意義是一切都是領受，沒有一件事由祂發起—約十六15，十七10，五19、30。

  4. 4.

    在以撒身上我們看見，一切都是從父而來，我們的地位乃是領受—創二六12～13，羅十一36，林前四7：

  5. 5.

    以撒與亞伯拉罕的關係是領受的關係；認識以撒的神，就是認識神是供給者—創二四36。

  6. 6.

    神是父，一切都從祂而出；我們是眾子，我們所有的一切，都從祂而來—林前八6，十一12下。

三、

雅各是對我們說到聖靈；他的經歷代表聖靈的工作，他的歷史豫表聖靈的管治：

  1. 1.

    雅各的一生乃是代表神的對付，而雅各的神乃是對付的神—創三一38～41：

  2. 2.

    『雅各的神』這名稱含示聖靈如何管教雅各，對付他的天然生命，把基督構成到他裏面，並且在他裏面結出聖靈的果子—加五22～23，來十二11。

  3. 3.

    我們要認識雅各的神，就得讓聖靈在我們身上作工，對付我們的天然生命，把基督構成到我們裏面。

  4. 4.

    雅各的歷史乃是一幅聖靈管治的圖畫—創四七9，四八15：

  5. 5.

    聖靈的管治是指聖靈在我們外面的環境裏作工，祂安排一切的人、事和遭遇，使我們藉此受管教—羅八28。

  6. 6.

    神藉着聖靈的管治，完全拆毀我們裏面舊造的元素，使新造的元素得以在我們裏面建造起來。

  7. 7.

    神藉着聖靈的管治，對付我們天然的生命，使基督得以作到我們裏面、構成到我們裏面並成形在我們裏面，使三一神得着團體的彰顯。

四、

亞伯拉罕的神、以撒的神和雅各的神，就是耶和華，伊羅欣—自有永有的三一神，永遠、偉大的我是—出三6、14，啓一4。

五、

亞伯拉罕的神、以撒的神和雅各的神，乃是復活的神—出三6、15，太二二23～33，徒三13。

六、

亞伯拉罕的神、以撒的神和雅各的神，乃是帳幕的神；亞伯拉罕、以撒和雅各都住在帳棚裏；他們住在帳棚裏時，熱切等候神永遠的帳幕，就是新耶路撒冷城—出四十34～35，創十二8，十三18，二六17、25，三三18，三五21，來十一9～10，啓二一2～3。

七、

亞伯拉罕的神是稱義的神（創十五6，羅四2～3），以撒的神是恩典的神（林後十三14），雅各的神是藉着神聖的管教變化人的神（三18，來十二5～11）；至終，雅各的神成了以色列的神（創三三20，出五1），就是經過變化之雅各的神。

第叁大點

經歷亞伯拉罕的神、以撒的神和雅各的神，結果乃是神的以色列，就是在三一神裏的召會—創三五10，三三20，加六16：

一、

神的以色列是真以色列人（羅九6下，二28～29，腓三3），包括在基督裏所有外邦和猶太的信徒，他們是亞伯拉罕的真子孫，是信仰之家的人，也是新造裏的人—加三7、29，六10、15～16：

  1. 1.

    真以色列人，屬靈的以色列人，乃是召會—16節，太十六18。

  2. 2.

    在神新約的經綸裏，我們已成爲神的兒子和神的以色列；我們的定命是作神的兒子彰顯神，並作君王在神的國裏掌權—加三26，六10、16，啓五10，二一7，二二5下，十二5上。

  3. 3.

    我們作爲神的以色列，代表神，行使祂的權柄，並在地上執行祂的行政，以完成祂的定旨—創一26、28，路十19，啓十二5、7～11。

二、

神的以色列乃是在三一神裏的召會—帖前一1，太二八19：

  1. 1.

    當保羅說到在父神和主耶穌基督裏的召會，事實上他的意思是說，召會是在三一神裏—帖前一1，林前一2，十二4～6：

  2. 2.

    『父神』和『主耶穌基督』這樣的說法，都含示那靈；因此，帖前一章一節含示那靈是不言而喻的，我們可以說，召會是在三一神裏的。

  3. 3.

    按照聖經，我們找不到召會只在神裏這回事；反之，召會乃是在經過過程的三一神裏—太二八19，林後十三14。

  4. 4.

    召會在父神和主耶穌基督裏，意思是說，召會乃是在經過過程的三一神裏，就是在那帶着父和子成了賜生命之靈的一位裏—太二八19，弗四4～6，約十四20。

  5. 5.

    我們若看見召會在三一神裏的異象，這異象會支配我們的思想、活動，以及我們整個的生活。
