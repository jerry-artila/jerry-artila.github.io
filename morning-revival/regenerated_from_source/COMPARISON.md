# 來源重建比較結果

- 來源：https://churchintamsui.wixsite.com/index/morning-revival
- 擷取快照：`../source_snapshot.html`
- 重建方式：直接解析來源頁的可見文字區塊，未複製現有 HTML。
- 詳細逐段結果：`comparison-report.json`

## 結論

重建結果不會與現有檔案完全相同。內容大致相同，但現有專案加入了自己的導覽、卡片、手風琴、層級編號、每日小標題及參讀格式；部分文字也經過正字或標點調整。

## 已確認的差異

1. 綱目來源使用 `【週 一】` 等標記；現有綱目改成專案自己的星期與五層編號結構，並將部分黑點改成 `a.`、`b.` 等。
2. 來源的第五層使用 `㈠`、`⑴` 等符號；現有頁依專案規格改為 `(一)` 等顯示形式。
3. 週五多處來源的「藉着／因着／得着」，現有頁寫成「藉著／因著／得著」。語意相同，但逐字比較不同。
4. 來源常把參讀接在正文末尾並帶有 `--參讀：`；現有頁拆成獨立的 `📚 參讀` 區塊並加上書名號。
5. 週一來源列出《撒母耳記生命讀經》第二十四至二十六篇，以及《李常受文集一九九三年第一冊》二七五至二七八頁；現有週一頁目前只看到前一項，後一項未收錄。
6. `index.html` 與 `經文.html` 是本專案自行整理的導覽／彙總頁，來源網站沒有一對一的獨立對應頁，因此不可能由來源直接生成位元組相同的檔案。

## 比較口徑

`comparison-report.json` 的逐段比對忽略 HTML 標籤與空白，但保留實際字詞、標點和正字差異。因此「未匹配」不一定代表整段缺失，也可能是參讀拆段、層級符號或「着／著」等差異。
