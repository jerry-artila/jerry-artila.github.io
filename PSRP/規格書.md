# 禱研背講 PSRP
Pray Study Recite Prophesy/Speak

## 1. 內容架構
- 每個子目錄代表一個主題，內含來源 PDF 文檔（例如：`亞伯拉罕以撒雅各的神/`）。
- 每個主題包含數個篇題（例如本主題共 9 篇）。
- 原 PDF 每一篇均包含「綱目」與「信息」兩部分：
  - **只輸出綱目部分**（以 PDF 中的「職事信息摘錄：」為分界，後續之信息內容不納入）。
  - 每篇篇題頁首資訊**僅保留「篇號」與「篇題」**（略去聚會時段、詩歌、讀經等標記）。

## 2. 綱目層級與編號規範
綱目依序分為五個層級：
1. **第一級**：壹、貳、參、肆、伍、陸、柒、捌、玖、拾...
2. **第二級**：一、二、三、四、五、六、七、八、九、十...
3. **第三級**：1、2、3...
4. **第四級**：a、b、c...
5. **第五級**：(一)、(二)、(三)... 或 ㈠、㈡、㈢...

## 3. 綱目引經（聖經經文）
- 條目下方引述之聖經經文，採無序 bullet（項目符號）逐條條列。
- 每節經文書卷節數（如：`創28:13`、`出3:6`）加粗標註，與經文內文有明確識別。
- 經文區塊配有淺色柔和底色與左側強調邊線，與綱目本文形成清晰層次。
- **個別項目收合按鈕**：引經展開／收合的控制按鈕直接設置於**各個別綱目項目文字之後**（僅有引經的項目才會顯示），供長者逐條點擊切換該項經文的展開或收合，頁首不擺放全局控制按鈕。

## 4. 適合年長者手機閱讀之字體與排版規範
### 4.1 字體大小比例（X、Y、Z 三級體系）
- **X 級（第一級綱目）**：綱目文字加大、加粗顯示。
- **Y 級（其餘各級內文）**：第二級至第五級之項目內文，統一維持 Y 級大小。
- **Z 級（引經文字）**：引經文字字體比 Y 級小一級（約為 0.85Y～0.88Y）。

### 4.2 綱目編號大小階梯縮小
- 第一級（壹、貳、參）：編號與內文同為 **X** 級（加粗）。
- 第二級（一、二、三）：項目內文為 **Y** 級，編號縮小為 **0.95 Y**。
- 第三級（1、2、3）：項目內文為 **Y** 級，編號縮小為 **0.90 Y**。
- 第四級（a、b、c）：項目內文為 **Y** 級，編號縮小為 **0.85 Y**。
- 第五級（(一)、(二) 或 ㈠、㈡）：項目內文為 **Y** 級，編號縮小為 **0.80 Y**。

### 4.3 年長者手機視距三大字級切換（頂部循環按鈕）
頂部導覽列設有字體切換按鈕，支援「中 ➔ 大 ➔ 特大」三段循環切換，各檔位具體尺寸如下：
| 字級檔位 | X（第壹級綱目） | Y（二至五級內文） | Z（引經文字） |
| :--- | :--- | :--- | :--- |
| **中（預設適中偏大）** | 24px (1.5rem) | 20px (1.25rem) | 17px (1.06rem) |
| **大（舒適大字）** | 28px (1.75rem) | 23px (1.44rem) | 20px (1.25rem) |
| **特大（極清晰大字）** | 32px (2.0rem) | 26px (1.63rem) | 23px (1.44rem) |

- **偏好記憶**：利用瀏覽器 `localStorage` 保存字體設定與經文收合狀態，長者再次開啟頁面時自動保持設定。

### 4.4 手機版面縮排與行距
- **懸掛縮排（Hanging Indent）**：各級編號靠左固定，多行文字換行時靠齊內文首字，不縮進編號下方。
- **階梯式輕量縮排**：針對手機寬度（360px～430px），每級縮排 12px～14px，避免第 4～5 級文字被過度擠壓折行。
- **舒適行高**：內文行高設定為 1.7～1.8，字距微寬，防範長者閱讀時跳行或視覺疲勞。

## 5. 導覽列與網頁介面元件
### 5.1 頂部固定導覽列（Sticky Header）
每篇篇題頁頂部常駐導覽列，高度適中、按鈕觸控區域大於 48x48px，包含：
1. **‹ 目錄**：一鍵返回該主題之篇題目錄頁。
2. **目前篇號**：例如「第一篇」，滾動時提示當前位置。
3. **字體切換按鈕**：顯示「字體: 中 / 大 / 特大」，點擊循環切換。

### 5.2 頁尾快速換篇導覽（Bottom Navigation）
每篇最下方提供大按鈕切換：
- **上一篇**（附篇名）
- **回目錄**
- **下一篇**（附篇名）

### 5.3 護眼色彩搭配
- 背景：米白護眼暖色調（如 `#FAF8F5` 或 `#FDFBF7`），減少藍光刺眼與螢幕反光。
- 文字：深炭灰高對比色（如 `#212529`），清晰易讀且柔和。
- 點綴色：典雅深藍或暗酒紅，用於標題、編號與導覽按鈕。

## 6. 網站檔案結構與輸出規範
每個主題目錄自成獨立完整網頁應用：
```text
PSRP/
├── index.html                   # 全站首頁：各主題總入口
├── 規格書.md                     # 本規格說明書
└── 亞伯拉罕以撒雅各的神/
    ├── 亞伯拉罕以撒雅各的神.pdf     # 來源 PDF 文檔
    ├── index.html               # 本主題首頁：篇題目錄（大卡片列表）
    ├── 01.html                  # 第一篇 獨立網頁
    ├── 02.html                  # 第二篇 獨立網頁
    ├── ...
    ├── 09.html                  # 第九篇 獨立網頁
    ├── style.css                # 針對長者手機優化之樣式檔
    └── script.js                # 字級切換、經文收合、偏好保存邏輯
```
- **目錄頁（`index.html`）設計**：
  - 顯示大字標題「總題：亞伯拉罕、以撒、雅各的神」。
  - 9 個篇題以「大卡片按鈕」條列，觸控高寬足夠（高度 ≥ 56px），字體清楚，便於長者點選。
