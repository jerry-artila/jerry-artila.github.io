# 本書網站的共用規範

本規範記錄使用者在第一至三章確認的修改，適用所有現有及後續篇章（全書預計十二章）。新增篇章時以 `templates/chapter.html` 為骨架，搭配共用 `style.css`、`reader.js`；不要重新加入已移除的文案。

## 內容

- 使用者提供章節文字後，完整轉為繁體中文，保留原文段落、經節、標題與順序，不改成摘要、不刪節，也不自行補寫未提供的章節。
- 簡繁轉換後檢查宗教用字、專有名詞與經文，沿用既有的「聖靈」「藉著」等寫法。
- 正文引經使用 `<mark class="scripture-quote">` 呈現淺藍底色，保留深色文字。逐處判斷是否為經文；一般對話、作者說明、禱告及詞義解釋不可只因有引號便標示。

## 手機閱讀與導覽

- 適合年長者手機閱讀，採單欄、暖白底、深色字，按鈕觸控區至少 56px。
- 字體預設 24px，循環為 22 → 24 → 26 → 22px；按鈕依目前字級顯示 A、A+、A++，並記住使用者選擇。保留無障礙名稱中的實際字級。
- 頁首固定於上方，同列放置「‹ 回目錄」、漢堡選單、字體大小按鈕。
- 漢堡選單預設收合，收納本章「讀經」和各級段落標題。選取後跳轉並收合；點外部或按 Escape 可收合。
- 目錄長標題必須自然換行、自動增高，禁止固定高度或壓縮而重疊。選單過長時可捲動。各標題錨點唯一且不被固定頁首遮住。
- 保留頂部「書名 / 第幾章」的位置導覽與章標題。章標題區不放「第幾章 · 繁體全文」標籤，也不在標題下方重複書名。
- 底部保留上一章／下一章（尚無下一章則回目錄）及回到本章開頭。未提供的章節不建立無內容的閱讀連結。

## 讀經卡片

- 章首「讀經」每一處引用各一張卡片；跨多節的同一處引用仍為一張，不把後面的正文包入卡片。
- 使用 `<p class="scripture-card"><strong class="scripture-reference">經節出處：</strong>經文</p>`。
- 經節出處獨立一行、加粗；卡片採樸素細框、淡底、少量圓角及留白，不加陰影或花俏裝飾。保留原有經文文字。

## 首頁

- 頁首名稱為「屬靈書報」，保留字體切換。
- 主區保留書名、篇章目錄、總章數。已提供的章節卡片只顯示數字、章名及箭頭，不放「第幾章 · 繁體全文」或章節介紹。
- 未提供章節列為「尚未提供」，不偽造章名及內容。
- 不放星形裝飾、宣傳副標、介紹文字、從第一章開始、繼續上次篇章、提供進度說明、閱讀提示卡片或首頁頁尾文字。
- 新增篇章時更新首頁卡片、移除對應待提供列、接上前後章連結。不要在首頁重新加入使用者已刪除的元素。

## 完成前檢查

- 核對提供的全部段落、標題及經節是否完整。
- 檢查卡片數、引經標示、各級目錄及錨點、首頁和前後章連結。
- 確認共用樣式及字體循環仍正常；可視化檢查可用時，檢查手機寬度與 26px 下的長目錄。無法預覽時如實說明，勿宣稱已實測。
